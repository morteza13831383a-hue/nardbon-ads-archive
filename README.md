# آرشیو تبلیغات تلگرام نردبون

هر ساعت تبلیغ‌های جدید فارسی/ایرانی تلگرام ادز رو از tgadsspy می‌گیره، تصویرها رو آماده می‌کنه و همراه پنل روی هاست دانلود (`dl.nardboon.com/tgads/`) می‌فرسته.

- `scripts/sync.py` اسکریپت اصلی
- `data/ads/*.json` دیتابیس اصلی (هر ماه یک فایل)
- `data/state.json` وضعیت همگام‌سازی
- `panel/` پنل کاتالوگ و وضعیت
- `.github/workflows/sync.yml` زمان‌بندی اجرا

Secrets لازم: `TGADS_API_KEY`، `FTP_HOST`، `FTP_USER`، `FTP_PASS`

اگه هاست در دسترس نباشه، همه‌چیز در صف می‌مونه و اجرای بعدی دوباره می‌فرسته.
